### Finding 1 - the Q-86 question sidecar quantifies C's late-discovery loss but suppresses A's

- **Severity:** low.
- **Evidence:** `docs/plans/agent-scaffold.questions/Q-86.md:9` tells the human that Option C "stops at pass three and leaves 23 later shortfalls undiscovered, including further highs". `Q-86.md:7` gives Option A no such figure; it says only that A "preserves more bounded late discovery than C on the descriptive Q-78 replay". The authoritative synthesis carries both tails (`Q-86-synthesis.md:97` "it would reach a terminal decision at pass seven, leaving three later low shortfalls undiscovered"; `:150` for C), and so does the queue entry (`agent-scaffold.plan.toml:2565`, rendered at `agent-scaffold.md:179`). Reproduce with `grep -n 'pass seven\|pass three' docs/plans/agent-scaffold.questions/Q-86.md docs/plans/workflow-calibration.explorations/Q-86-synthesis.md docs/plans/agent-scaffold.plan.toml`.
- **Reasoning:** `Q-86.md` is a human-facing projection, inlined verbatim into the generated plan's `## Question Details` as the fuller account behind the one-line queue entry. In it, the only option carrying a quantified discovery penalty is the one the recommendation rejects, while the option that also terminates early is described purely by the comparative that favours it. A cold reader who goes from the queue line to the detail block gets a less balanced account than the summary they came from, and could reasonably conclude A has no late-discovery cost. This is the same defect class the Q-86 synthesis round-1 triage already ruled valid (`q86-synthesis-r1-triage.md:55`: "In the synthesis, C only carries the qualitative pass-three statement ...; A's result and both quantitative tails are absent"); that fix reached the synthesis and the TOML ask, and this sidecar - newly authored in this pass, previously a one-line pointer - reproduces the imbalance. It is low, not medium, because the missing figure is present in the same rendered document at `agent-scaffold.md:179` and in the authoritative artefact, so the information is not lost, only unevenly placed.
- **Correction:** Add A's replay tail to `Q-86.md:7` in the same form the synthesis and the TOML ask already use ("On the descriptive Q-78 replay it stops at pass seven and leaves three later low shortfalls undiscovered"), and re-render.

### Finding 2 - Option A's reviewer allocation is not derivable, so its cheapest acceptance row is unexplained

- **Severity:** low.
- **Evidence:** The shared proposed safety package binds all three architectures: "Every ordinarily completing acceptance path reserves blind closure evidence" (`Q-86-synthesis.md:72`). Option B prices that batch (`:105` "the phase has one non-transferable blind-closure batch") and Option C now prices it explicitly after the round-1 T4 fix (`:137,146`). Option A's controller section (`:79-93`) never mentions a blind or informed seat: `:79` says only "Acceptance requires one settled pass after every earlier in-scope finding and Roadmap step is settled", and `:87` says only "With two reviewer calls ... per phase". The cost table consequently gives A the cheapest acceptance row, "One batch and two reviewer calls" (`:158`), against C's "Two batches and three reviewer calls", with no stated reason. The source proposal does supply the missing allocation - `Q-86-state-machine.md:171`: "The first batch uses one broad blind seat and one rubric-focused seat with no finding history" - but that sentence is not in the decision artefact. The retained prototype (descriptive only) shows the same asymmetry: `--mode A --phase acceptance --risk risky --floor high` reports `min_reviews=1` and carries no `bad_acceptance_blind_bypass` control, while mode C reports `min_reviews=2` and does carry that control, and mode B at two obligations reports `min_reviews=3`.
- **Reasoning:** This is the exact gap the round-1 triage ruled valid as T4, whose reasoning was that an unstated allocation "makes C appear to have an unexplained minimum-cost advantage in the cost comparison". The repair closed it for C and left A as the only row in the table whose reviewer allocation the artefact does not state, which moves the unexplained advantage rather than removing it. The number itself appears defensible, so this is a derivability and comparability defect, not a wrong bound: a human weighing acceptance cost cannot tell whether A is cheaper because it is leaner or because its blind-closure evidence is a seat inside the single batch rather than an independent post-repair sample. It is low for the same reason T4 was: it documents a proposed cost allocation and does not touch the deferred selected-option proof, which already covers the substance through the failure path at `:205` ("admits a delivery path that violates the selected safety package").
- **Correction:** In Option A or the cost table, state A's per-batch seat allocation as the source proposal does - one blind seat and one rubric-focused or informed seat per batch - and say that A's single settled acceptance pass supplies the shared blind-closure evidence through its blind seat rather than through a separate batch. Do not change any bound.
