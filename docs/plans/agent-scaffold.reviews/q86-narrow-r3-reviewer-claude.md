- **Severity:** low.
- **Evidence:** `Q-86-synthesis.md:103` states that "B reuses A's sealed controller for plan review", and `:105` defines the obligation count only for post-freeze phases: "For post-freeze phase `q`, let `n_q = |O_q|`."   ```sh

  ```sh
  # | Low-risk plan or work phase | ... | `n_q + 1` batches and `2(n_q + 1)` reviewer calls | ... |
  # | Risky plan or work phase    | ... | `n_q + 1` batches and `2(n_q + 1)` reviewer calls | ... |
  # | Whole family                | ... | `r_plan + |O| + m + 1` batches                    | ... |
  ```

  Rows one and two put `n_q + 1` in B's cell for a phase the same table's row four prices at `r_plan`, and `n_q` has no value for plan review at all. The other two human-facing surfaces get this right and were corrected for exactly this reason: `Q-86.md:8` says "Proposed clean **post-freeze** phase minimum `n_q + 1`", and `agent-scaffold.plan.toml:2566` (rendered at `agent-scaffold.md:179`) says "The proposed **post-freeze** phase minimum is `n_q + 1`".
