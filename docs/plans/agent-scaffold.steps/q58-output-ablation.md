### Increment 1, `q58-output-ablation-inc1`

RISK CLASS `risky` (two consecutive clean review rounds). The increment changes no product code, but its result selects the carrier used by resume, the currency signal and the typed driver. A false result commits several later steps to the wrong substrate and is expensive to unwind; the high-leverage decision, not code blast radius, sets the class.

ACCEPTANCE.

1. Before the first trial, the run records a fresh `next` measurement with exact command, source commit and input paths and reports bytes, lines, words and tokens. It compares that measurement with the canonical historical provenance in the retained design without requiring equality; no old ~6 KB, 150145-byte or roughly 728 KB figure is a current pass condition.
2. Every design variant that remains representable is run. A dropped or changed variant is named with evidence from the current source. V4 remains the oracle-circularity control unless the result demonstrates a stronger independent control.
3. The frozen protocol is a commit ancestor of every generated trial/result commit and fixes exact non-placeholder values for the margin, confidence level, interval/test method, state ids and weights, replicate aggregation, missing-trial policy, model classes/weights, cross-model aggregation, model-disagreement rule and tie-break before any result is observed. Each comparison then uses fresh consuming agents, the fixed structured response request, stratified derivable/transient states and at least two model classes. A changed protocol after observation invalidates and restarts the run rather than reclassifying the same results post hoc.
4. Tier-B truth comes from git reality and not from the resume prose under test. The Q-59 currency gate is scored on every carrier candidate.
5. A retained aggregate file plus checked-in analysis script or exact mechanical command reproduces the per-model classifications, weighted aggregate, disagreement disposition, Pareto frontier and selected carrier from the frozen protocol. The frozen non-inferiority/equivalence procedure and its margin decide admission to the plateau. Descriptive marginal/per-arm confidence intervals, their overlap and point estimates are never decision rules; a paired confidence bound may implement the decision only when that exact paired method was precommitted in the protocol, and a precommitted paired hypothesis test remains the other permitted implementation. The result states what the experiment cannot conclude and preserves the oracle-circularity boundary: it measures resume-carrier value but does not independently prove the ACTIVE LOOP action that supplies Tier-A truth.
6. No file under `src/`, `tests/`, `pack/` or `Cargo.toml` changes. The changed paths are the pre-run protocol, result, retained aggregate/analysis files the result needs, followed by the planner-authored Q-58 question/step/dependency updates and decision receipt needed to open and decide Q-58.
7. Both validation modes, strict render check, tests, Clippy, diff checks and ASCII checks pass after the result and decision fold.
